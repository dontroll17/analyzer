# Stream Sensation Analyzer - Этап 1 (PoC)

## Базовый захват аудио и вывод FFT в консоль

---

## Установка расширения

1. Откройте Chrome и перейдите в `chrome://extensions`
2. Включите **Режим разработчика** (Developer mode) в правом верхнем углу
3. Нажмите кнопку **"Загрузить распакованное расширение"** (Load unpacked)
4. Выберите папку `c:\analyzer` (где находится manifest.json)

---

## Использование

### Важное замечание:
В Manifest V3, `chrome.tabCapture.capture` **не может вызываться напрямую из service worker**. Она должна быть вызвана в контексте **popup** или **page action**.

### Запуск захвата аудио:
1. Откройте страницу с аудиопотоком (например, YouTube, Spotify, или любой сайт с музыкой)
2. Активируйте вкладку с аудиопотоком
3. Нажмите на значок расширения в панели инструментов
4. Нажмите кнопку **"Start Capture"** в popup меню
5. Вы должны услышать звук, но теперь он также анализируется расширением

### Остановка захвата:
1. В popup меню нажмите кнопку **"Stop Capture"**
2. Статус изменится на "Not Connected"

## Проверка результатов

### Место просмотра:
Откройте **консоль браузера** (F12 → вкладка Console) на странице, где работает расширение.

### Ожидаемые логи:
```
Starting audio capture...
Active tab: [Название вкладки]
Audio stream captured: MediaStream {...}
AudioContext created
AnalyserNode created with fftSize: 1024
Connected to AnalyserNode
Connected to destination (audio playback)
AudioContext resumed
Audio capture started successfully
FFT Data (first 20 bins): [12, 15, 18, 22, 25, 30, 35, 40, 45, 50, ...]
RMS Value: 0.1234
```

### Что проверять:
1. **FFT Data**: Массив из 20 значений частотных данных (0-255)
2. **RMS Value**: Среднее значение громкости (должно меняться с аудио)

## Известные ограничения Этапа 1:

### Функциональные ограничения:
- ❌ Только базовый захват без продвинутой обработки
- ❌ Вывод только первых 20 значений FFT (для проверки)
- ❌ Нет UI визуализации (только консоль)
- ❌ Нет обработки аномалий
- ❌ Нет настроек чувствительности

### Технические ограничения:
- ⚠️ Захват работает только на активной вкладке
- ⚠️ Нет сохранения состояния после перезагрузки
- ⚠️ Минимальная обработка ошибок

---

## Решение проблем

### "Tab capture error: Access denied" или "Access to the requested resource is denied":
- Убедитесь, что расширение вызывается из popup (не из service worker)
- Проверьте, что вкладка активна
- Убедитесь, что на вкладке воспроизводится звук
- Убедитесь, что другие расширения не используют tabCapture

### "Permission denied":
- Перезагрузите расширение
- Проверьте права в `chrome://extensions` (включите расширение)

### Нет данных в консоли:
- Убедитесь, что аудиопоток активен
- Проверьте, что нажата кнопка "Start Capture"
- Убедитесь, что консоль открыта и не очищается

### Звук пропал:
- Это нормально при остановке захвата
- При активном захвате звук должен воспроизводиться нормально
